# @app/support-chat-react

Виджет посетителя и инбокс оператора поверх `@app/support-chat-client`. Свой CSS на переменных `--scw-*`:
UI-кит приложения и Tailwind у проекта не нужны, стили сайта и чата друг друга не задевают.

```tsx
import { SupportInbox, SupportWidget } from '@app/support-chat-react'
import '@app/support-chat-react/styles.css'

<SupportWidget
  client={visitorClient}
  assetBaseUrl={apiUrl} // база для путей файлов от сервера
/>

<SupportInbox
  client={operatorClient}
  operatorId={me.id}
  selectedId={id}
  onSelect={setId}
  onError={showToast}
  assetBaseUrl={apiUrl}
/>
```

Для своей раскладки экспортируются и части: `MessageList`, `Composer`.

Готовая обвязка для копирования в проект — `examples/`: клиенты (`support-clients.ts`), плавающий виджет
для корневого лейаута (`SupportChatWidget.tsx`), страница инбокса (`SupportOperatorPage.tsx`), тема
(`support-theme.css`). Места под проект помечены `// ЗАМЕНИТЬ:`. Полная установка с сервером — `INSTALL.md`
пакета `@app/support-chat-nest`.

## Виджет посетителя

| Проп | Что |
| --- | --- |
| `client` | `SupportVisitorClient` |
| `assetBaseUrl` | база для путей вложений (адрес API) |
| `locale` | тексты интерфейса, частично — по умолчанию русский |
| `startOnMount` | подключиться сразу, чтобы работал счётчик непрочитанного (по умолчанию `true`) |
| `defaultOpen` | открыть окно без нажатия на кнопку |
| `offsetBottom` | отступ кнопки снизу, если внизу страницы своя панель |
| `className` | класс корня |

Что умеет:

- плавающая кнопка; при непрочитанных вместо значка — их число и мягкая пульсация, пока окно закрыто;
- окно с полупрозрачной шапкой поверх ленты; на телефоне — во весь экран;
- лента прижата к низу, история догружается при прокрутке вверх, без прыжков при появлении полосы прокрутки;
- ответ на сообщение: кнопка при наведении, свайп влево на телефоне; цитата в пузыре ведёт к оригиналу
  (догружая историю, если он выше);
- картинки — скрепкой или вставкой из буфера, просмотр галереей;
- время сообщения — «11:57 23 октября», статус «доставлено / прочитано» под пузырём;
- операторы для посетителя безымянные — везде «Оператор».

## Инбокс оператора

Список диалогов с фильтрами по статусу и поиском, лента выбранного диалога, взять себе / закрыть / открыть снова,
заметки для коллег (ответ на заметку — тоже заметка), имена коллег у их сообщений.

## Тема

Тёмная тема — класс `.dark` выше по дереву или `data-theme='dark'` у корня. Под дизайн приложения —
переопределить переменные у `.scw-root`, удобнее всего сославшись на токены своей темы:

```css
@import '@app/support-chat-react/styles.css';

.scw-root {
  --scw-font: var(--font-sans);
  --scw-bg: var(--background);
  --scw-text: var(--foreground);
  --scw-accent: var(--primary);
}

/* Кнопка чата не должна перекрывать нижнее меню на мобильном */
@media (max-width: 767px) {
  .scw-widget {
    --scw-offset-bottom: 96px;
  }
}
```

| Переменные | Что |
| --- | --- |
| `--scw-font`, `--scw-radius`, `--scw-radius-bubble`, `--scw-shadow` | шрифт (по умолчанию — шрифт сайта), скругления, тень окна |
| `--scw-bg`, `--scw-surface`, `--scw-border`, `--scw-text`, `--scw-muted` | фон, подложки и поле ввода, границы, текст |
| `--scw-accent`, `--scw-accent-text` | кнопка чата, значок в шапке, кнопка отправки, «прочитано», полоска цитаты, «печатает…» в списке инбокса |
| `--scw-action`, `--scw-action-text` | обычные кнопки, активная вкладка инбокса |
| `--scw-own-bubble`, `--scw-own-text`, `--scw-other-bubble`, `--scw-other-text` | свои и чужие сообщения |
| `--scw-note-bubble`, `--scw-note-text` | внутренние заметки операторов |
| `--scw-danger`, `--scw-success` | ошибки, «оператор онлайн» |
| `--scw-offset-bottom`, `--scw-offset-side` | отступ плавающей кнопки от края экрана |

Если в системе включено «уменьшить движение», анимации отключаются.

## Разработка стилей

Разметка — на Tailwind v4 с префиксом `scw:` (`scw:flex`, `scw:hover:bg-surface`), точка входа — `src/styles.css`.
`yarn build` собирает из неё `dist/styles.css` (`yarn dev` — то же в watch), проект подключает только готовый файл.

- Префикс и утилиты без `@layer` — чтобы классы и стили чужого сайта не задевали чат, и наоборот.
- Цвета в разметке — только токены темы (`scw:bg-surface`, `scw:text-muted`), они смотрят на `--scw-*`. Хексы — лишь
  там, где цвет не должен зависеть от темы проекта.
- Размеры в px (`--spacing: 4px`), не rem: у чужого сайта может быть любой размер шрифта у `html`.
- Две утилиты одного свойства на одном элементе (`scw:bg-action` и `scw:bg-transparent`) не смешиваем — победит не
  последняя в `className`, а последняя в CSS. Варианты кнопок — целиком, см. `src/ui.ts`.
